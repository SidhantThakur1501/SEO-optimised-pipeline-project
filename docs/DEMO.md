# Demo Guide

## Option 1: Terminal demo

Run:

```bash
npm run demo
```

What it shows:

- sample blog topic input
- intent classification
- SERP-style gap analysis
- keyword clustering
- prompt generation
- draft article generation
- SEO score output
- quality gate output

## Option 2: UI demo for GitHub

Use this flow when recording a short video or taking screenshots:

1. Open the app with `npm run dev`
2. Go to the new project flow
3. Enter a topic and keywords
4. Walk through the pipeline stages
5. Stop on the final SEO and quality results screen

Recommended GitHub demo assets:

- `docs/demo.png` for a screenshot
- `docs/demo.mp4` for a screen recording

If you add a screenshot, reference it from the main README with:

```md
![SEO Blog Generator demo](docs/demo.png)
```
